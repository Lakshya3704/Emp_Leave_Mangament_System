# Employee Leave Management System

A comprehensive web-based application for managing employee leave requests, approvals, and tracking within an organization. This system streamlines the leave management process, providing an intuitive interface for both employees and administrators.

## Features

### Employee Features
- **Submit Leave Requests**: Easy-to-use form to request leaves with customizable date ranges
- **Track Leave Balance**: Real-time view of available and used leave days
- **Request History**: View all past and pending leave requests
- **Request Status**: Monitor approval status with notifications
- **Update Profile**: Manage personal and professional information

### Administrator Features
- **Approve/Reject Requests**: Review and manage employee leave requests
- **Employee Management**: Add, edit, and manage employee records
- **Leave Policy Configuration**: Set company-wide leave policies and limits
- **Reports & Analytics**: Generate comprehensive leave reports and statistics
- **Audit Trail**: Track all leave-related activities and changes

### System Features
- **Role-Based Access Control**: Secure access with different user roles
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Data Validation**: Client-side and server-side validation for data integrity
- **Search & Filter**: Quick and efficient leave request search and filtering

## Usage

### For Employees

1. **Log in** with your credentials
2. **View Dashboard** to see leave balance and recent requests
3. **Submit Leave Request**:
   - Click "Request Leave"
   - Select leave type (Sick, Personal, Vacation, etc.)
   - Choose date range
   - Add optional remarks
   - Submit for approval
4. **Track Status** in the "My Requests" section

### For Administrators

1. **Log in** with admin credentials
2. **Navigate** to the Admin Dashboard
3. **Review Requests** in the approval queue
4. **Take Action** by approving, rejecting, or requesting modifications
5. **Generate Reports** for leave analytics and trends
